# Body Upgrade — Кузница Тела

Мобильное веб-приложение для ведения силового цикла (3 тренировки/нед, 4-недельный цикл: 2 силовые + 2 объёмные недели) в фэнтези-сеттинге: герой, уровни, статы, вердикты «отработал / схалявил».

## Стек
- Чистые ES-модули, без сборщика — деплоится на Vercel как статика
- Программа цикла: `data/program.js`
- Знаки отличия (100 достижений, 6 рангов): `data/achievements.js`; иконки достижений — `data/icons-achievements.js`
- Журнал: localStorage + экспорт/импорт JSON-файла (кнопки в профиле)

## Локальный запуск
```bash
npx serve .
# или python3 -m http.server 8000
```

## Тесты
```bash
node --test tests/achievements.test.mjs
```
Тестируется бизнес-логика достижений: пороги, счётчики повторяемых, миграция старых статусов.

## Знаки отличия
100 уникальных достижений в шести рангах: бронза → серебро → золото → алмаз → изумруд → титан.
Уникальные (вехи, клубы силы, серии) выдаются один раз; повторяемые (рекорд, безупречный квест, тоннаж за квест,
дары судьбы) при каждом новом получении увеличивают счётчик ×N. У каждого знака есть журнал получений:
дата и причина (тоннаж и квест, рекорд с килограммами, время, серия) — виден в раскрытии знака. Правила — чистые функции над контекстом
(`buildAchievementCtx` в `js/app.js`), список и оценка — `data/achievements.js`.
Иконки — game-icons.net (CC BY 3.0); новые вытаскиваются скриптом `tools/extract-icons.py` из локального клона библиотеки.

## Деплой
Пуш в main → Vercel собирает автоматически (Framework Preset: Other, без build command, output = корень).

## Логика вердикта
Счёт = 65% покрытие плановых подходов + 35% работа в своей весовой вилке (движение дня весит ×2).
- ≥85% — «Испытание пройдено»
- 60–84% — «Достойно, но не всё»
- <60% — «Схалтурил, странник»

XP → уровень героя. Статы: СИЛА (рост расчётных 1ПМ от базы 147/170/195/100), ВЫНОСЛИВОСТЬ (средний тоннаж), ДИСЦИПЛИНА (частота за 14 дней), СТОЙКОСТЬ (средний счёт).
